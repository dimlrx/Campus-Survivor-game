# Campus Survivor — Enschede 2.5D Edition

This edition keeps Java, Saxion GameApp, the original Gradle wrapper and Sprint 0–3 gameplay.

## Changes
- More detailed walkable roads, pedestrian paving, crosswalks, trees, campus benches and six architectural landmark illustrations.
- A top-down 2.5D view is now the default; press **V** to toggle the experimental isometric view.
- Existing building entrances, collisions, NPC routines, interiors, actions, exams and statistics are preserved.
- Small HUD text from the Sprint 3 HUD Fix is preserved.

## Important accuracy note
This is a **stylized, Enschede-inspired game map**, **not an accurate geographic map or imported OpenStreetMap street network**. The Saxion, Oude Markt, Kennispark and other structures are artistic approximations. No third-party 3D models or proprietary map assets are included.

## Run
Windows: `gradlew.bat run`
macOS/Linux: `bash gradlew run`

The archive has been checked for ZIP integrity, but has not been compiled or visually tested in this environment.
