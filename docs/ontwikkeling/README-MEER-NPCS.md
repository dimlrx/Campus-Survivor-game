# Meer NPC's — Campus Survivor

Deze editie bouwt voort op de 2.5D-gebouwenversie. Het aantal NPC's is verhoogd van 4 naar 12.

Nieuwe NPC's: Mila (groepsproject), Jesse (Jumbo), Lotte (budget), Daan (Java-tentamen), Yara (Oude Markt), Bram (Kennispark), Sophie (studieplek), Rayan (studentenflat).

Elke NPC heeft een dag-/avondroutine en een gesprek met drie keuzes, meerdere stappen en gevolgen voor statistieken. Loop naar een NPC en druk E. Gebruik 1/2/3 om te antwoorden, Q om af te sluiten.

De bestaande kaart, sprites, foto-interieurs, missies en spelregels zijn behouden. Volledige Gradle-compilatie en grafische tests zijn niet uitgevoerd in deze omgeving.
