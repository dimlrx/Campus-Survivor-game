# Campus Survivor: Enschede Edition — Sprint 3

This builds on Sprint 2 Interiors Edition, preserving the original Gradle project, 2.5D map, interiors, NPCs and activities.

## Added in Sprint 3
- Compressed 21-day semester with three automatic exams on days 7, 14 and 21.
- Exam scores depend on knowledge, energy, stress and alcohol.
- Random campus events every two days (except exam days): broken laptop, free pizza, unhelpful teammate, extra work shift, viral presentation.
- Five possible endings, based on exam performance, stress, popularity and money.
- End-of-semester result screen, exam count and days remaining.

## Controls
WASD move; E enter building/talk; Q exit; 1 study, 2 sleep, 3 work, 4 go out at the correct location; V switch camera; P pause; ESC menu; N menu after the semester.

## Run
Windows: `gradlew.bat run`
macOS: `bash gradlew run`

## Important
The world is a stylized 2.5D game environment, not a geographically accurate Enschede reconstruction or actual imported 3D models. Build and runtime testing on a local computer are still required. Sprint 3 delivers gameplay code; final technical documentation, slide presentation and demonstration are separate project deliverables.
