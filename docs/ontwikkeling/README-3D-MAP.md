# Campus Survivor — Landmark Edition

This version retains the complete Sprint 2 Java/SaxionGameApp project and enhances its procedural 2.5D architecture.

## Distinctive buildings
- Saxion: glass campus atrium and repeated glazed academic facade.
- Student flat: balcony rhythm and multi-storey facade.
- Kennispark: glass-and-steel office blocks.
- Oude Markt: stylized stepped gables and cafe fronts.
- Centrum: rows of retail shopfronts.
- Shops/work: retail-industrial facades.

The map is an **artistic, fictionalized layout**, not surveyed streets or a photogrammetric reconstruction of Enschede. True 3D and accurate real-world streets/building models require additional map data and a 3D renderer. The original WASD, collision, NPC, clock, stats and Sprint 2 activities remain unchanged.

Run with `./gradlew run` on macOS/Linux or `gradlew.bat run` on Windows. Requires Gradle dependency access. Runtime compilation not verified here.
