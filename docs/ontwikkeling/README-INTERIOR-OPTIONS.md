# Interior options update

- Enter a building using E.
- Inside any building, press 1, 2, or 3 to perform the corresponding displayed mission (no M modifier).
- Inside the Studentenflat only, a fourth option is displayed: `[4] Sleep in your bed (8h)`.
- Press 4 while inside the Studentenflat to sleep. The sleep option is not displayed in other interiors or outdoors.
- Press Q to exit.
- Outside buildings, 1/2/3/4 continue to trigger the original location-based activities at their matching entrances.

The complete game still requires a local Gradle build and visual playtest.
