# Campus Survivor - 2D stadskaart

Deze editie bevat een nieuwe, top-down getekende 2D-kaart van Enschede,
in `src/main/resources/maps/enschede_centrum_2d.jpg`.

- De kaart toont de zeven bestaande speelbare locaties: Saxion,
  Studentenflat, Kennispark, Centrum, Oude Markt, Jumbo / Werk en Enschede CS.
- De kaart wordt als wereldachtergrond geladen in `CampusGameScreen.java`.
- De transparante 2.5D-gebouwen worden bovenop de kaart getekend.
- WASD, camera, botsingen, NPC's, missies en foto-interieurs zijn behouden.
- Dit is een **Enschede-geinspireerde speelkaart** met plaatsnamen en een
  aangepaste wegenstructuur, **geen geografisch exacte OpenStreetMap-kaart**.
  De spelwereld is bewust gecomprimeerd om alle zeven locaties te kunnen spelen.
- Een live Java-build en volledige gameplaytest zijn niet uitgevoerd.
