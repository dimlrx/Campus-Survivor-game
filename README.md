# 🎮 Campus Survivor: Enschede Edition

**Release 2 | Java • SaxionGameApp • Gradle**

*Overleef het studentenleven in Enschede!*

Campus Survivor: Enschede Edition is een interactieve 2.5D-game waarin je het leven van een student in Enschede ervaart. Verken de stad, ontmoet medestudenten, voer missies uit en probeer een goede balans te vinden tussen studeren, werken, slapen en uitgaan.

Elke keuze heeft gevolgen voor je statistieken, je reputatie en uiteindelijk je studieresultaten.

---

## 🌆 De gamewereld

De game bevat een geïllustreerde 2.5D-kaart van Enschede met zeven herkenbare locaties. Je kunt vrij rondlopen, gebouwen betreden en verschillende activiteiten uitvoeren.

**Belangrijkste kenmerken:**

- 🗺️ Een interactieve 2.5D-kaart geïnspireerd op Enschede.
- 🧍 Een speelbaar pixel-artpersonage met vrije beweging.
- 👥 12 NPC's met interacties en dialogen.
- 🚪 Interactieve gebouwen met oplichtende groene ingangsmarkeringen.
- 🏫 Gebouwinterieurs gebaseerd op echte locaties en foto's.
- 🎯 21 missies verspreid over zeven locaties.
- 📚 Tentamens, willekeurige gebeurtenissen en verschillende eindresultaten.

## 🕹️ Besturing

| Toets | Actie |
|---|---|
| `W` `A` `S` `D` | Personage bewegen |
| `E` | NPC aanspreken of gebouw binnengaan |
| `Q` | Gebouw verlaten |
| `1` `2` `3` | Missie of activiteit selecteren |
| `4` | Slapen in de studentenflat |
| `TAB` | Kaartoverzicht openen |
| `P` | Game pauzeren |

Tijdens het spelen moet je rekening houden met verschillende statistieken.

| Statistiek | Betekenis |

| 💰 Geld | Verdien geld door te werken en geef het uit |

## 🎯 Missies en activiteiten

In Campus Survivor kun je verschillende activiteiten uitvoeren:

- **Studeren:** vergroot je kennis en bereid je voor op tentamens.
- **Werken:** verdien geld om je studentenleven te bekostigen.
- **Slapen:** herstel je energie.
- **Uitgaan:** ontmoet andere studenten en beïnvloed je reputatie.
- **NPC-interacties:** voer gesprekken en ontdek nieuwe mogelijkheden.
- **Missies:** voltooi opdrachten op verschillende locaties.

Naast de vaste activiteiten kunnen willekeurige gebeurtenissen optreden die je voortgang beïnvloeden.

## 💻 Installatie en starten

### Benodigdheden

- Java Development Kit (JDK), passend bij de Gradle-configuratie.
- Windows, macOS of Linux.
- Een IDE zoals IntelliJ IDEA (optioneel).

### Starten op Windows

1. Download of clone de repository.
2. Open de projectmap in een terminal.
3. Voer het volgende commando uit:

```powershell
.\gradlew.bat run
```

### Starten op macOS of Linux

```bash
./gradlew run
```

De Gradle Wrapper verzorgt het gebruik van de geconfigureerde Gradle-versie.
